# Firmware

STM32CubeIDE dual-core project for the STM32H747I-DISCO.

- `CM7/` camera capture, pre-processing, AI inference (STM32Cube.AI)
- `CM4/` FreeRTOS: ToF, fusion, audio, haptics, buttons
- `Common/` shared message structures and HSEM ids

See [../docs/SOFTWARE.md](../docs/SOFTWARE.md). Code arrives in Phase 1.
